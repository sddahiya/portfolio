# Saurabh Dahiya — Cybersecurity Portfolio

A modern, dark-themed personal portfolio website showcasing cybersecurity and networking projects.

## 🚀 Live Demo
[View Portfolio](#) *(Update with your Vercel URL after deployment)*

## 🛠️ Tech Stack
- HTML5 / CSS3 / Vanilla JavaScript
- Google Fonts (Inter + Fira Code)
- Font Awesome Icons
- Particle.js-style animated background
- Fully responsive design

## 📁 Project Structure
```
portfolio/
├── index.html          # Main HTML
├── style.css           # All styles
├── script.js           # Interactivity & animations
├── vercel.json         # Vercel deployment config
├── images/             # Project screenshots
│   ├── project1.png    # Encapsulation dot1Q
│   ├── project2.png    # GRE Tunnel
│   ├── project3.png    # Multi-Router Network
│   ├── project4.png    # RHEL Firewall Automation
│   └── project5.png    # SELinux Hardening Toolkit
└── README.md
```

## 📸 Adding Project Images
Place your project screenshots in the `images/` folder:
- `project1.png` → Encapsulation dot1Q
- `project2.png` → GRE Tunnel
- `project3.png` → Multi-Router Network Connection
- `project4.png` → RHEL Firewall Automation
- `project5.png` → SELinux Hardening Toolkit

## 🔗 Update Your Links
Open `index.html` and search for `href="#"` to update:
- LinkedIn URL
- GitHub URL
- Project demo & repo links

## 🚀 Deploy to Vercel
1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Import your GitHub repo
4. Click Deploy — done!
